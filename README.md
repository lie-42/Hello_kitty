# ✈️ 짐싸기 도우미 (공항 반입 규정 RAG 챗봇)

## 1. 목적
해외여행을 앞둔 사람들은 짐을 쌀 때마다 "보조배터리는 몇 개까지 되지?", "이건 기내에 들고 타야 하나, 부쳐야 하나?", "술은 몇 병까지 면세지?"를 헷갈린다. 게다가 이 규정은 자주 바뀌어서(예: 2026년 4월 보조배터리 1인 2개 제한), 일반 챗봇이나 오래된 블로그 글은 예전 규정으로 틀리게 답하는 경우가 많다.
슬랙에서 물품을 물어보면 **공식 최신 문서에서 근거를 찾아** 기내 반입·위탁 가능 여부와 조건을 **출처와 함께** 답해주는 챗봇을 만든다.

## 2. 기능
- 기능 1: 물품 반입 질문 답변 — "고데기 기내에 들고 타도 돼?" → 기내/위탁 가능 여부 + 조건(개수·용량 등) + 출처 문서와 기준일
- 기능 2: 입국 면세 한도 질문 답변 — "위스키 2병 사 와도 면세야?" → 면세 기준과 초과 시 신고 안내
- 기능 3: 모르는 질문 처리 — 문서에서 근거를 못 찾으면 지어내지 않고 "문서에서 확인 불가, 이용 항공사에 확인하세요"라고 답변

## 3. 사용 모델과 선택 근거 ★
- 생성 모델: `EXAONE-3.5-7.8B-Instruct` (4bit 양자화, Q4_K_M) — *4주차 비교표 기준으로 최종 확정 예정*
- 임베딩 모델: `BAAI/bge-m3`
- 근거:
  - 생성 모델: 4주차 비교표의 **한국어 성능** 항목 — 질문과 문서가 모두 한국어라서 한국어 이해·생성 능력을 가장 중요하게 봄. 7~8B급이면서 4bit로 줄이면 8GB 안에 들어감
  - 임베딩 모델: 한국어를 포함한 다국어 검색 성능이 좋고, "보조배터리 ↔ 리튬배터리"처럼 표현이 달라도 의미가 비슷하면 찾아줌
- VRAM 계산: **약 6.5 GB → 8GB 안에 들어감 ✅**
  - 생성 모델: 7.8B × 0.5바이트(4bit) ≈ 3.9GB + 실행 여유분(KV 캐시 등) 약 1.5GB = 약 5.4GB
  - 임베딩 모델: 약 0.57B × 2바이트(FP16) ≈ 1.1GB
  - 합계: 5.4 + 1.1 ≈ **6.5GB** (8GB 대비 약 1.5GB 여유)

## 4. 사용 스택
- LangChain:
  - `DirectoryLoader` / `PyPDFLoader` — MD·PDF 문서 불러오기
  - `MarkdownHeaderTextSplitter` + `RecursiveCharacterTextSplitter` — 문서 자르기
  - `HuggingFaceEmbeddings` (bge-m3) — 조각을 숫자(벡터)로 변환
  - `Chroma` — 벡터 저장소
  - `Retriever` (top-k = 4) — 질문과 비슷한 조각 4개 검색
  - `ChatPromptTemplate` + `ChatOllama` — 검색된 조각을 붙여 답변 생성
- LangSmith: ★ 필수 — 아래 3곳에 추적을 붙인다
  1. **검색 단계(Retriever)**: 질문마다 어떤 조각이 뽑혔는지 → 엉뚱한 조각이 나오면 분할·임베딩 문제로 판단
  2. **생성 단계(LLM 입력/출력)**: 조각이 붙은 최종 프롬프트와 답변 → 문서에 없는 내용을 지어냈는지 확인
  3. **전체 체인 응답 시간**: 슬랙 답변이 너무 느린 구간 찾기
- LangGraph: 사용 안 함 (질문 → 검색 → 답변의 단순한 한 줄 흐름이라 필요 없음)
- 기타: `slack_bolt` (Socket Mode) — 슬랙 봇 연결, `Ollama` — 로컬 모델 실행

## 5. 실행 방법
> ⚠️ 3교시 실습 후 실제로 실행해 본 순서대로 다시 확정할 예정

```bash
# 1) 설치
git clone <저장소 주소>
cd airport-packing-bot
pip install -r requirements.txt
ollama pull exaone3.5:7.8b

# 2) 환경변수 설정 (.env 파일)
SLACK_BOT_TOKEN=xoxb-...
SLACK_APP_TOKEN=xapp-...
LANGSMITH_API_KEY=...
LANGSMITH_TRACING=true
LANGSMITH_PROJECT=airport-packing-bot

# 3) 문서를 잘라서 벡터 저장소에 넣기 (최초 1회, 문서 바뀔 때마다)
python ingest.py

# 4) 슬랙 봇 실행
python app.py
```

## ⚠️ 안내
이 챗봇은 공식 문서를 근거로 답하지만 **참고용**이다. 항공사·국가별로 규정이 다를 수 있으므로 출국 전 이용 항공사에 최종 확인해야 한다.
